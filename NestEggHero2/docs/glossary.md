# Glossary

- **Assumption:** An input accepted for an estimate.
- **Effective year:** The year in which a financial rule applies.
- **Hydration:** Applying persisted data to application state.
- **Migration:** Converting persisted data from one schema version to another.
- **Projection:** A calculated scenario, not a guaranteed result.
- **Schema:** A machine-readable definition of allowed data.
- **Semantic token:** A design token named for purpose rather than raw color.
- **State:** Data representing the user's current application experience.
- **WCAG:** Web Content Accessibility Guidelines.
