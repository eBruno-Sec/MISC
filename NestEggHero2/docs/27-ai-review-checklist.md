# AI Review Checklist

Score 1–10:

- Functional preservation
- Information hierarchy
- Accessibility
- Mobile usability
- Performance
- Security
- State resilience
- Financial accuracy
- SEO
- Conversion ethics
- Maintainability
- Visual polish

Then classify findings:

- Blocker
- Critical
- Major
- Minor
- Enhancement

Every finding must include evidence, user impact, recommended fix, and acceptance test.
