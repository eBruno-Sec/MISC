# Error Handling

Errors must answer:

1. What happened?
2. Was anything saved?
3. What can the user do next?
4. Can the action be retried?
5. How can support identify the incident?

Examples:

- “This backup file is not valid. Your current progress was not changed.”
- “We could not save locally because browser storage is full. Download a backup before clearing space.”
- “The projection could not be calculated with these values. Check that the return rate is above -100%.”

Never blame the user.
