# NestEggHero Documentation Pack

This folder is the operating knowledge base for the NestEggHero educational blog and financial-learning platform.

## Authority order

1. Applicable law, regulation, and official government guidance
2. Product requirements and signed engineering decisions
3. These Markdown documents
4. Design mockups
5. AI-generated recommendations

## Required AI behavior

- Read `00-ai-system-prompt.md` first.
- Read the topic-specific files relevant to the task.
- Never present changing tax, retirement, or Social Security figures without a source and effective year.
- Separate facts, assumptions, estimates, and recommendations.
- Preserve existing workflows unless an approved requirement explicitly changes them.
- Prefer progressive enhancement, accessibility, privacy, and resilience.

## Versioning

Every material rule change must update the relevant document's `Last reviewed` date and changelog.
