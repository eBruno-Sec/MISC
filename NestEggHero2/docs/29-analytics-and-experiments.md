# Analytics and Experiments

## Event principles

- Collect the minimum data necessary.
- Do not send highlighted text, quiz free-response content, imported backup contents, or sensitive financial inputs to analytics by default.
- Use stable event names and documented properties.
- Separate product analytics from advertising.

## Core events

- article_started
- article_completed
- kid_speak_enabled
- activity_completed
- calculator_started
- calculator_completed
- backup_exported
- backup_import_succeeded
- backup_import_failed
- cta_viewed
- cta_activated

Experiments require a hypothesis, primary metric, guardrail metrics, duration, audience, and stopping rule.
