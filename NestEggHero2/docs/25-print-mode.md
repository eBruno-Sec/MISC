# Print Mode

Print output must:

- Remove navigation, ads, sticky CTAs, comments, and decorative backgrounds.
- Preserve title, author, last-reviewed date, assumptions, results, disclosures, and sources.
- Avoid clipped tables and charts.
- Repeat table headers across pages where supported.
- Use high-contrast ink-friendly colors.
- Expand collapsed content required to understand results.
- Show URLs or source labels meaningfully.
- Avoid orphaned headings.
- Include page-break rules for cards and result sections.
