# Content Style Guide

## Article structure

1. What you will learn
2. Plain-language summary
3. Core explanation
4. Example
5. Interactive activity
6. Risks and exceptions
7. Key takeaways
8. Sources
9. Next lesson

## Kid Speak

Kid Speak must preserve the core meaning, uncertainty, and risks. It may simplify vocabulary but must not change legal or financial substance.

## Reading level

Default public explanations should target broad readability. Advanced definitions remain available through progressive disclosure.
