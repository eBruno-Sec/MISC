# Fact-Check Report

**Review date:** 2026-07-16  
**Package:** NestEggHero documentation

## Result

The package was reviewed against current primary sources. The original package was primarily a governance framework and contained few numeric financial claims. This update adds verified 2026 facts and corrects standards language.

## Corrections and clarifications

1. Added verified 2026 IRA, employer-plan, SEP, SIMPLE, phaseout, Saver's Credit, and Social Security figures.
2. Clarified that WCAG 2.2 AA's target-size minimum is 24×24 CSS pixels with exceptions; 44×44 remains NestEggHero's stronger internal standard.
3. Updated OWASP ASVS to version 5.0.0.
4. Clarified that NIST SSDF 1.1 is final while the newer revision is draft.
5. Clarified that structured data does not guarantee rich results.
6. Added Trump Account authority-status controls so proposed regulations are not presented as final.
7. Added RMD distinctions for IRAs, workplace plans, Roth accounts, beneficiaries, and aggregation.

## Limitations

- This is not a legal opinion.
- State tax rules were not added.
- Plan documents can impose additional restrictions.
- Future updates require a new review.
