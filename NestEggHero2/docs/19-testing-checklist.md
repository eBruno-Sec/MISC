# Testing Checklist

Before release, verify:

- Mobile, tablet, desktop
- Portrait and landscape
- Light and dark themes
- Keyboard-only operation
- Screen reader smoke test
- 200% zoom
- Reduced motion
- Print preview and PDF output
- Offline resume
- JSON export
- Valid import
- Corrupted import
- Old-schema migration
- Empty, loading, success, and error states
- Slow and interrupted network
- Long text and localization expansion
- Large and negative numbers
- Calculator boundary values
- Analytics events
- Structured data
- Canonical URL
- Core Web Vitals
- Security headers
- Dependency scan
