# Offline Mode

## Supported offline actions

- Read previously cached articles
- Resume saved learning
- Complete local quizzes
- Run deterministic calculators
- Export progress

## Rules

- Clearly indicate stale or unavailable dynamic facts.
- Do not claim current tax limits while offline unless the effective year is explicit.
- Queue safe writes and reconcile later.
- Detect conflicts.
- Keep core navigation functional.
- Version service-worker caches.
- Provide a recovery path from corrupted caches.
