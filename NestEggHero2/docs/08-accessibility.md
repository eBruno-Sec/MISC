# Accessibility

**Last fact-check:** 2026-07-16  
**Conformance target:** WCAG 2.2 AA.

## Target sizes

- WCAG 2.2 AA Success Criterion 2.5.8 uses a 24×24 CSS-pixel minimum with defined exceptions.
- NestEggHero adopts 44×44 CSS pixels as a stronger internal product standard for primary controls.
- Do not claim that 44×44 is WCAG's normative AA minimum.

## Verified requirements

- Normal text contrast: at least 4.5:1.
- Large text contrast: at least 3:1.
- Required UI visual information and states: at least 3:1 against adjacent colors.
- Text resizing to 200% without loss of content or function.
- Reflow at a width equivalent to 320 CSS pixels, except inherently two-dimensional content.
- Keyboard-complete workflows, unobscured focus, accessible authentication, and alternatives to dragging.
