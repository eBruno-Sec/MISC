# Component Library

Required reusable components:

- App shell
- Header and mobile navigation
- Breadcrumbs
- Article header
- Reading progress
- Table of contents
- Kid Speak toggle
- Definition popover
- Scenario decision card
- Projection chart
- Assumption panel
- Disclosure panel
- CTA block
- Badge and learning progress
- Bookmark control
- Highlight control
- Quiz
- Results summary
- Export progress action
- Import drop zone
- Error banner
- Toast
- Empty state
- Skeleton
- Accessible modal
- Drawer
- Tabs
- Accordion
- Data table
- Print-only result header

Each component requires documented states: default, hover, focus, active, disabled, loading, empty, success, warning, and error.
