Scan intensity (how hard we hit each target)

Independent of mode (which controls what's allowed). Intensity controls how deep each heavy tool digs — e.g. sqlmap L1R1 → L3R2 → L5R3. Deep/Insane require Full mode. Truth-first is unchanged: heavier settings find more candidates, never more confirmations.

Vulnerability scanners (Full mode)

Intrusive & slow. Both produce truth-first advisory leads (version/behaviour/template-based — verify before reporting), never confirmed findings. The default fast scan already runs safe-tag nuclei.

Lab packs (benchmark / training targets)

Isolated from the general detector — solves the lab's own challenges end-to-end to prove exploitation. No brute-force, no DoS. Same idea as Burp scan profiles / Nuclei tags: activate the pack for the target you're on.
