Independent of mode (which controls what's allowed). Intensity controls how deep each heavy tool digs — e.g. sqlmap L1R1 → L3R2 → L5R3. Deep/Insane require Full mode. Truth-first is unchanged: heavier settings find more candidates, never more confirmations.

Vulnerability scanners (Full mode)

Intercept Proxy

Burp-style MITM — capture, rewrite in flight, replay. The browser routes through it automatically.
A real intercepting proxy (mitmproxy) sits between Apolaki's headless browser and every target: it captures every request/response in one ledger and can rewrite traffic in flight with deterministic match-and-replace rules (Burp's match-and-replace, but reproducible). Start it with docker compose --profile proxy up -d mitmproxy — no manual proxy config, no CA import. Off by default; the HTTP + browser engines work fine without it.
